# Contributing to MetaPilot

Welcome! We are excited that you want to contribute to MetaPilot.

To ensure a smooth process, please read our in-depth contributing policies and coding standards:

👉 **[Contributor Guidelines (docs/Contributing.md)](file:///c:/Users/user/OneDrive/Desktop/MetaPilot/docs/Contributing.md)**

## Quick Start Check List

1. **Issues**: Check the issue tracker for duplicates before creating a new report.
2. **Setup**: Follow the [Setup Guide](file:///c:/Users/user/OneDrive/Desktop/MetaPilot/docs/SetupGuide.md) to set up your environment.
3. **Coding Standards**:
   - Python code must be formatted using `black`.
   - TypeScript/React code must conform to Vite configurations and use custom HSL CSS tokens.
4. **Pull Requests**:
   - Create a feature branch from `main`.
   - Ensure all backend tests run and pass: `cd backend && pytest`.
   - Keep commits clean and follow semantic styling guidelines (e.g. `feat: ...`, `fix: ...`).
