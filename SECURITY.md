# Security Policy

We take the security of MetaPilot seriously. If you believe you have found a security vulnerability, please report it immediately through our secure channel.

Please read our full security disclosure process:

👉 **[Security Guidelines (docs/Security.md)](file:///c:/Users/user/OneDrive/Desktop/MetaPilot/docs/Security.md)**

## Reporting a Vulnerability

Please do not open a public GitHub issue for security-sensitive bugs. Send reports to:

📧 **security@metapilot.io**

We will acknowledge receipt within 24 hours and arrange a patch within 10 days. Thank you for helping keep MetaPilot secure!
