# MetaPilot Screenshot Capture Plan

This document maps out the required screenshots for the MetaPilot submission and release gallery, detailing UI views, configurations, and caption descriptions.

---

## 📸 Screenshots Checklist & Captions

### 1. Landing Page
* **Focus**: The dark-themed landing page showcasing cards, key features, and authentication links.
* **Caption**: *"The MetaPilot landing page highlighting core data engineering agent capabilities, security structures, and setup details."*

### 2. Authentication (Login / Register)
* **Focus**: The login card with input validation alerts.
* **Caption**: *"Secure credentials interface leveraging bcrypt passwords verification and JWT token authorization checks."*

### 3. Dashboard Overview
* **Focus**: Central control panel listing quick actions, linked catalog assets count, and recent operations history.
* **Caption**: *"The MetaPilot operations dashboard showing connected catalog tables, execution counts, and active workflows."*

### 4. Metadata Explorer
* **Focus**: Database catalog catalog tree listing Snowflake schemas, tables, tags (e.g. `PII`, `Core`), and ownership properties.
* **Caption**: *"The Metadata Explorer interface parsing platform tables, tags, and column profiles retrieved from LinkedIn DataHub."*

### 5. Lineage Viewer
* **Focus**: Interactive relationship graph canvas mapping upstream and downstream dataflow nodes.
* **Caption**: *"Programmatic lineage tree mapping dependencies across Snowflake, Postgres, and transactional tables."*

### 6. AI Workspace
* **Focus**: Split-pane layout displaying the chat area on the left and the code editor workspace on the right.
* **Caption**: *"The interactive MetaPilot Workspace, where engineers prompt the agent and review streamed reasoning pipelines side-by-side with code."*

### 7. Generated SQL Model
* **Focus**: The editor pane showing a compiled Snowflake JOIN query with primary key matching comments.
* **Caption**: *"Fully qualified SQL JOIN query compiled by MetaPilot, grounded in schemas retrieved from the catalog."*

### 8. Generated dbt Configuration (YAML)
* **Focus**: The code editor showcasing dbt `schema.yml` configurations with column details and null tests.
* **Caption**: *"Automatically synthesized dbt model configurations and tests schema matching Snowflake table properties."*

### 9. Generated Airflow DAG (Python)
* **Focus**: The code editor displaying Python TaskFlow DAG code utilizing decorators (`@dag`, `@task`).
* **Caption**: *"Python Airflow pipeline orchestrations generated by MetaPilot to schedule transformations daily."*

### 10. Diagnostics Explainability Panel
* **Focus**: The right-side sidebar presenting token gauges, prompt templates, and validation checklist summaries.
* **Caption**: *"The Diagnostics Observability sidebar showing token gauges, prompt versions, and schema validations results."*

### 11. Settings Panel (General & Connections)
* **Focus**: API configurations showing Gemini key parameters, database endpoints, and connection status cards.
* **Caption**: *"System settings interface where users configure LLM provider keys and verify DataHub connection status."*

### 12. Hackathon Judge Mode Toggle
* **Focus**: The Settings page under the "Experimental Beta" tab, displaying the Hackathon Judge Mode toggle.
* **Caption**: *"Persistent LocalStorage toggle forcing the Workspace to display granular RAG telemetry for reviewers."*

### 13. System Architecture Diagram
* **Focus**: Mermaid flowchart rendering system nodes (React, FastAPI, Postgres, Redis, Chroma, DataHub).
* **Caption**: *"Decoupled system architecture mapping clients, server APIs, and backend vector databases."*

### 14. Real-time Analytics Dashboard
* **Focus**: Analytics charts presenting request counts, execution latencies, and token logs over time.
* **Caption**: *"The Analytics panel tracking request volumes, server latency performance, and model token usage metrics."*

### 15. Export ZIP Attachment
* **Focus**: Dialog window confirming packaging of generated assets into a download-ready ZIP archive.
* **Caption**: *"Workspace export confirmation downloading compiled SQL, dbt config, and Airflow orchestrations as a single package."*

---

## 🛠️ Capture Guidelines

1. **Resolution**: Keep browser dimensions at 1920x1080 for clear text readability.
2. **Theme**: Verify the dark theme is active to preserve custom CSS aesthetics.
3. **Mock Data**: Use seeded database entries to display representative text and charts in the explorer and analytics views.
